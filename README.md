# EcoExplora 🌿
App mobile para catalogação de espécies ameaçadas do Rio Grande do Sul.

Desenvolvido como projeto de feira científica no ensino médio, o EcoExplora nasceu da ideia de tornar acessível uma informação crítica: quais animais do Rs estão desaparecendo e quantos ainda restam.

# O que é
Um catálogo interativo de espécies ameaçadas no Rio Grande do Sul. O usuário navega pelas caterogias, abre uma espécie e encontra seu grau de risco de extinção e a estimativa de população remanascente

# Funcionalidades
Catálogo de espécies organizado por caterogia
Nivel de risco de extinção por espécie (Crítico, Em perigo, Vulnerável)
Estimativa de população remascente
Integração com API externa para dados
Backend próprio para catalogação e gerenciamento das espécies

# Tecnologias
```
Java - Android nativo
Backend - Api REST com integração de dados de espécies
Android SDK
```
